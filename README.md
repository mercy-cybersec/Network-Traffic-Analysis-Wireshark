# Network Traffic Analysis Using Wireshark

## Project Overview

This project demonstrates network traffic monitoring and packet analysis using Wireshark. The object is to capture and analyze communication patterns and identify potential security threats. 

## Objectives

- Capture network packets using Wireshark
- Analyze DNS traffic
- Examine HTTP communication
- Study ICMP packets
- Understand network protocols and structures

## Tools Used

- Wireshark
- TCP/IP Protocol Suite
- DNS Protocol
- HTTP Protocol
- ICMP Protocol

## Activities Performed

### Packet Capture
Captured live network traffic during web browsing activities.

### DNS Analysis
Monitored DNS queries and responses.

### HTTP Analysis
Inspected HTTP requests and responses generated while browsing websites.

### ICMP Analysis
Captured ICMP packets generated using ping commands.

### Protocol Statistics
Reviewed protocol hierarchy and traffic distribution.

## Learning Outcomes

- Network Monitoring
- Packet Analysis
- Cyber Security Fundamentals
- Protocol Investigation
- Traffic Analysis Techniques
